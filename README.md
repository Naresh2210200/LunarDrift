# Lunar Drift

Source code and Play Store assets for **Lunar Drift**, a papercraft-style endless-runner game built in Godot 4.

## Privacy Policy

The privacy policy required for the Google Play Store listing is hosted via GitHub Pages from this repo:

**Live URL:** https://naresh2210200.github.io/LunarDrift/privacy-policy.html

- Source file: [`privacy-policy.html`](./privacy-policy.html)
- Covers: local-only game data (no accounts), and Google AdMob rewarded ads
- To update: edit `privacy-policy.html`, commit, and push to `main` — GitHub Pages redeploys automatically within ~30–60 seconds

## Game

Built with Godot 4. See in-editor project settings for autoloads, input map, and mobile control configuration.
